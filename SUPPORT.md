# Support

- Use GitHub Discussions for design questions and workflow ideas.
- Use GitHub Issues for reproducible bugs and feature requests.
- Use a private security advisory for vulnerabilities.

When reporting a bug, attach:

- StoryCanvas version/commit;
- ComfyUI backend and frontend versions;
- Python and operating system versions;
- execution mode and provider names/models (never keys);
- sanitized `canvas_plan.json`, `run_manifest.json`, and relevant receipt;
- the smallest fictional input that reproduces the issue.

Provider billing, moderation, account access, and service availability must be handled with that provider.
