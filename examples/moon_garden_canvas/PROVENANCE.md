# Moon Garden demo provenance

This directory is a sanitized, read-only export of a completed three-shot StoryCanvas Run.
It contains no API credentials, provider request IDs, remote task IDs, or machine-local paths.

- Planning and image assets: StoryCanvas with Codex ImageGen.
- Shot videos: MiniMax-H3, 1344×768, 24 fps, approximately 10 seconds each.
- Story: a fictional botanist plants a silver seed, grows a blue vine, and releases three glowing moths.
- Export: deterministic `storycanvas/canvas/v1` media DAG with content-addressed local media.
